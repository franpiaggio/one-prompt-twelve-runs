# Francisco Piaggio — Portfolio

## Build Details

- **Claude model**: minimax-m2.7
- **Skill used**: frontend-design

## Overview

A personal portfolio page for Francisco Piaggio, Senior Frontend Engineer and Creative Coder based in Buenos Aires, Argentina.

## Features

- Profile photo with grayscale filter and hover effects
- Name, roles, and tagline prominently displayed
- Current employment at Deel with external link
- Location information
- Contact links (GitHub, X/Twitter, Email) with animated hover states
- Responsive design for mobile and desktop
- Subtle noise texture overlay
- Staggered entrance animations

## Tech Stack

Pure HTML and CSS — no frameworks required. Uses Google Fonts (Cormorant Garamond and JetBrains Mono).

## Local Development

Simply open `index.html` in a browser. No build process needed.

## Notes

Place your profile photo at `/profile.png` in the same directory as `index.html`.
