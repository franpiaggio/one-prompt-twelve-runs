Slides

Thirteen 1080 × 1080 squares ready for LinkedIn carousel. Open the deck (← → to navigate), or export every slide as a PNG with the script below.

Export to PNG

From the repo root, with a static server running on http://localhost:4000:

cd slides && bash capture.sh

Outputs slide-01.png through slide-13.png into slides/exports/, each at exact 1080 × 1080 pixels. Upload them to LinkedIn as a multi-image post; they'll render as a carousel in the feed order.
